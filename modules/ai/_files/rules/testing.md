# Tests: den Skill `testing` laden

Wer Tests schreibt, ändert oder reviewt, lädt zuerst den Skill `testing`. Er beschreibt, wie
Mutationen die Tests prüfen, welche Abdeckung zählt, woher Testdaten kommen, wie
eigenschaftsbasierte Tests und Fuzzing gelenkt werden und wie Tests deterministisch bleiben.

Die Quelle des Skills liegt im nix-darwin-Repository unter
`modules/ai/_files/skills/testing/`, neben dieser Regel (`modules/ai/_files/rules/`).
